
## 🛍️ Buy-It – eCommerce Website Frontend

**Buy-It** is a fully responsive and modern **static eCommerce website** built using **HTML, CSS, and JavaScript**. It mimics the look and feel of a real online shopping platform, complete with product listings, categories, navigation bar, and responsive sections like newsletter signup and featured banners.

### ✨ Features

* 🛒 Fully responsive layout
* 🎯 Hero banner with CTA
* 🧺 Product cards with star ratings & pricing
* 🧭 Interactive navbar with shopping cart icon
* 📱 Mobile-friendly hamburger menu
* 📩 Newsletter subscription section
* 🖼️ Footer with useful links and payment methods

### 🧪 How to Run Locally

```bash
git clone https://github.com/GovindxSharma/Buy-It.git
cd Buy-It
open index.html  # or double click the file
```

No dependencies needed — it’s a purely static website!
